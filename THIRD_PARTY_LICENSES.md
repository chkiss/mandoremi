# Third-party data and code

Mandoremi bundles or depends on the following third-party works. Their
licenses are reproduced or summarised here so the public repository is
license-clean.

## Data

### CC-CEDICT (shipped in `data/cedict.u8.gz`)
- **Source:** CC-CEDICT, published by MDBG (https://www.mdbg.net/chinese/dictionary).
- **License:** Creative Commons Attribution-ShareAlike 4.0 International
  (CC BY-SA 4.0). The full text is at
  https://creativecommons.org/licenses/by-sa/4.0/
- The dictionary file carries this notice in its header:
  `# CC-CEDICT` / `# Community maintained free Chinese-English dictionary.` /
  `# Published by MDBG` / `# License: Creative Commons Attribution-ShareAlike
  4.0 International License`.

### HSK 3.0 word lists (`data/hsk-*.txt`)
- **Source:** `krmanik/HSK-3.0` (https://github.com/krmanik/HSK-3.0).
- Used under that project's terms; please consult the upstream repository for
  the authoritative license.

### THUOCL 成语 lexicon (`data/chengyu.txt`)
- **Source:** THUOCL (Tsinghua Open Chinese Lexicon), 成语 subset
  (http://thuocl.thunlp.org/).
- Used under THUOCL's terms; consult the upstream source for the authoritative
  license.

### Generated data (NOT shipped)
- `data/user_dict.txt` and `data/leaderboard_snapshot.json` are generated by
  `tools/` and are gitignored. They are derived from the above sources plus
  Mandoremi's own corpus.

## Code dependencies
Python dependencies (FastAPI, uvicorn, spacy-pkuseg, OpenCC, pypinyin,
requests, …) are listed in `requirements.txt` and carry their own licenses;
none are vendored into this repository.
